1 What is new in this version

Since 25 November 2026, the iOS app has a new icon and a new design. The web app has its own sign-in screens. Summaries are more complete, and the five other languages are now translations of one checked English text. A review of 31 real and sample documents found nine defects; all have a fix and a test. Deploys now start only after CI passes for a push to this repository.

1.1 Changes in the product

AreaChangeChapter
App iconA new icon: a letter rises out of an open envelope, one line is marked in highlighter yellow, and a yellow lens reads it. There are light, dark and tinted variants for iOS 18 and later. The old icon had white corners outside its outline; the new drawing has closed, joined outlines.13
iOS designShared components (ink capsule buttons, chips, pills, toasts, skeletons, progress bars, highlighter marks), animated illustrations, and restyled screens. The letter list shows the next deadline, a usage bar and a floating scan button.13, 15
Web sign-inThe web app has its own screens for sign-in, sign-up, e-mail code, password reset and MFA. They call the Cognito user-pool API directly (ADR-9).14, 18
Account deletion"Delete my account" now also deletes the sign-in account in Cognito, not only the data in the database.9, 10
Complete summariesThe summary names the decision, the conditions, the consequences, the actions and the permissions. A signed receipt form (Empfangsbekenntnis) is a required action.7, 11
TranslationThe model writes the explanation once, in English. Code checks it. Then the model translates it item by item, and code puts the line links back. Before, each language was written separately, and the languages differed in content.7
NamesThe recipient's name is hidden also when OCR adds noise, and also when the name is only in the greeting ("Sehr geehrte Frau …"). The surname alone is hidden too.8, 10
Own domainCloudFront can use an own domain name and certificate (optional).16

1.2 Changes from tests and reviews

FindingResult
31 real and sample documents were read with Apple Vision and run through the live pipeline. A person checked every result. Nine defects found and fixed, each with a test. Examples: a placeholder date shown as a real date; a fine notice classified as "benefits"; assessed tax shown as "to pay". Details in chapter 11.6.
Two test files reused details of a private letter. They now use an invented office, person and situation. The shorter test letter found a real gap: the date on a signed receipt form was taken as the letter date. The rules extractor and the verifier now stop at the heading of the receipt form.
The classifier had no vocabulary for fines and courts. New vocabulary, a new letter family (traffic fine), and a retrained model: 99.1 % on unseen layouts.
The corpus had no passage for fines and hearing forms.Passage 27 (OWiG, StVG). The corpus now has 27 passages.

1.3 Changes in delivery

  • The Deploy workflow starts only after CI passes for a push to main of this repository. A pull request from a fork can never start a deploy.
  • The deploy role can read the Parameter Store path also with a trailing slash. A test in infra/tests proves it.
  • The iOS release configuration contains the production addresses of the API and of Cognito.
