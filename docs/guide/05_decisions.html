Decisions that came from tests and measurements

Several design points were not planned. A test or a measurement showed a problem, and the design changed:

  • The classifier first scored 50 % on unseen layouts. Domain vocabulary in the training data and calibration on held-out layouts raised it to 97.8 %.
  • A check against the live law text showed that "Bürgergeld" became "Grundsicherungsgeld" on 1 July 2026, with a 30 % reduction for missed appointments. The corpus and the letter templates were updated.
  • A hand-written injection letter showed that a planted date could pass the grounding check, because the date was really in the line. Suspicious lines are now excluded as sources.
  • The first live run hit a billing error, and the evaluation silently measured the rules fallback. The live gate now requires 0 degraded letters.

13 Status, limits and next steps

The code, tests, evaluation and documentation are complete. The database, the model provider and the AWS account are set up. The first deploy waits for AWS to verify the account for CloudFront.

Done

  • Backend, web app, iOS app, infrastructure, CI/CD, documentation.
  • Neon database migrated; secrets in Parameter Store and GitHub; deploy role with OIDC.
  • Live evaluation with Mistral: every gate passed; six languages enabled.

Known limits

  • Test letters are synthetic and hand-written; real consented letters are missing.
  • The 24 corpus passages and the legal boundary need a review by a counsellor and a lawyer.
  • The iOS app compiles against the iOS SDK but has not run on a device yet (no simulator runtime on this Mac).
  • Person names outside the address block are not pseudonymized.
  • Only nationwide public holidays are known; regional ones keep deadlines in "please check".

Next steps

  1. AWS verifies the account → deploy → smoke test → first counselling service.
  2. Turn on MFA for the AWS root user.
  3. Run the iOS app on a device; set the production values in ios/Config/Release.xcconfig; TestFlight.
  4. Pilot with one counselling service; collect consented letters for the golden set.
  5. Legal review of the boundary; counsellor review of the corpus; privacy policy and DPIA.
