10 Code tour: the iOS app

SwiftUI with an @Observable app model and small services. All logic that does not need UIKit is in the Swift package LetterLensCore, which swift test runs on a Mac without a simulator. Real API responses are decoded in tests, so a server change cannot silently break the app.

10.2 LetterLensCore (Swift package)

  • Models.swift: Codable structs for every response. The decoder converts snake_case and parses Python timestamps with 6 fractional digits (APIClient.parseISODate; ISO8601DateFormatter alone cannot).
  • APIClient.swift: async methods per endpoint; APIError with the server's error code.
  • Logic.swift: PKCE (tested against the example in RFC 7636), DocumentBuilder (Vision boxes have their origin at the bottom left; the builder flips them and sorts rows), Deadlines (days until, urgency, reminder date).

10.3 Purchases with StoreKit 2

The app buys app.letterlens.plus.monthly with .appAccountToken(userId), which binds the purchase to the LetterLens account. It sends the signed transaction (jwsRepresentation) to the server. The server verifies Apple's signature chain itself and refuses a transaction whose account token belongs to another user. App Store Server Notifications V2 keep the plan current after renewals and refunds.

10.4 Tests and build

swift test runs 11 tests on macOS, including the contract tests. ios/scripts/typecheck.sh compiles the whole app against the iOS simulator SDK with swiftc, for Macs and CI runners without a simulator runtime. The Xcode project is generated from ios/project.yml with XcodeGen.

11 Infrastructure, delivery and cost

All AWS resources are Python code (AWS CDK) in infra/. GitHub Actions tests every change and deploys the main branch without stored AWS keys. At pilot volume, hosting costs 0 € per month; the language model costs about 0.3 cents per letter.
[[aws_infra]]

11.1 Infrastructure as code

infra/letterlens_infra/stack.py defines every resource. Notable details:

  • Lambda functions use ARM processors (cheaper) and Python 3.13. infra/scripts/build_lambda.sh installs Linux ARM wheels on a Mac without Docker.
  • The letters bucket has a fixed name. This avoids a dependency cycle (bucket → CloudFront → API → bucket) that CloudFormation cannot resolve.
  • Cognito client ids reach the API through Parameter Store for the same reason.
  • cdk-nag checks the template against AWS security rules. Each exception has a written reason in infra/app.py.
  • Eight assertion tests check the template, for example "every bucket blocks public access" and "at most 10 alarms" (the free limit).

11.2 Delivery

[[ci_cd]]

The deploy job signs in to AWS with GitHub OIDC: GitHub proves the repository and environment, and AWS gives a temporary role that can only use the CDK deployment roles. No long-lived AWS keys exist. Database migrations run before the deploy. A smoke test checks /health, the web page, and that the API refuses requests without a token.
